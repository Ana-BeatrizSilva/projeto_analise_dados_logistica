# Planejamento do Projeto

## Objetivo

Desenvolver uma análise de dados sobre vendas e operações logísticas, utilizando dados fictícios para identificar padrões de faturamento, produtos, regiões e entregas.

## Perguntas de negócio

- Qual é o faturamento total?
- Qual é o ticket médio dos pedidos?
- Quais são os produtos mais vendidos?
- Qual região possui maior faturamento?
- Qual região possui menor faturamento?
- Quantas entregas estão atrasadas?
- Qual é o percentual de entregas atrasadas?

## Dados

O dataset foi dividido em quatro tabelas:
- PRODUTOS
- CLIENTES
- PEDIDOS
- ENTREGAS

## Ferramentas

- Google Sheets / Excel — criação e organização dos dados
- Python — análise exploratória e visualizações
- Pandas — manipulação dos dados
- Matplotlib — visualização dos dados
- Power BI — modelagem e dashboard
- DAX — criação de medidas
- GitHub — documentação e portfólio

## Escopo

O projeto possui finalidade educacional e utiliza dados fictícios. Os resultados representam exclusivamente o dataset desenvolvido para a análise.
